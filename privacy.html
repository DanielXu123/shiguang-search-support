使用帮助隐私政策

隐私政策

更新日期：2026 年 10 月 27 日
适用产品：拾光快搜 iPhone App，当前 0.1.0 版本。

让照片留在你的设备上，是拾光快搜的基本原则。

1. 我们如何处理照片

获得你的照片权限后，App 在设备上读取已获准访问的静态照片及其相关信息，用于识别图像类别、照片上的文字、拍摄时间、图片属性和照片记录的拍摄 GPS，并建立本地检索索引。索引包含查找照片所需的关联信息、识别结果与文字位置；搜索词及最近一次搜索状态也保存在 App 内。

照片、识别文字、标签、拍摄地点和搜索词不会由 App 上传给开发者或其他服务器，也不会用于广告、跨 App 跟踪或云端模型训练。App 无需注册账号，不包含广告或第三方行为分析服务。

2. 权限与选择

你可以授权全部照片，也可以只授权选定照片；App 仅处理已获授权的内容。你可以随时在 iPhone 的系统设置中更改或撤回照片权限。撤回权限可能使照片浏览和检索不可用。

地点筛选只使用照片已经记录的 GPS，不需要获取手机当前实时位置。App 不访问通讯录、麦克风或相机，也不读取或同步系统相册中的人物姓名。

3. 数据存储与系统相册

检索索引、识别结果、必要缓存和搜索状态保存在 App 的本地存储区域。App 不修改原照片、系统相册标签或系统人物数据，不提供自身的云同步服务。你对系统照片、iCloud 和设备备份的选择由 iOS 单独管理。

照片删除或授权范围变更后，App 在收到变更通知或下次核对图库时更新对应索引。

4. 清理与删除

你可以通过「索引 → 管理 → 清理缓存」删除可清理的临时数据，保留已有索引。通过「重建本机索引」可以清除并重新生成检索索引。通过「清空搜索结果」可以清除当前搜索状态。

在 iOS 中选择「删除 App」会移除该 App 的本地数据；「卸载 App」可能按 iOS 的规则保留文稿与数据。以上操作不会删除系统照片。开发者没有可代为删除的照片或搜索云端副本。

5. 诊断与主动联系

App 可在本机保存有限的运行状态和耗时信息，用于恢复任务和排查问题，不会自动发送给开发者。你主动通过支持邮箱或 GitHub 联系我们时，我们会收到你自行提供的信息，仅用于处理该次咨询或故障，并按处理所需期限保留。

请勿发送不必要的私人照片、证件、精确地点或其他敏感信息。GitHub Issues 为公开页面；邮件及 GitHub 的处理规则也适用于你主动选择的联系渠道。

6. Apple 与本支持网站

App 的分发、TestFlight 测试以及你选择的系统分析和崩溃报告功能，由 Apple 按相应条款和你的系统设置处理。此类 Apple 服务与 App 自身在设备上的检索处理不同。

本支持网站托管在 GitHub Pages，不嵌入广告、统计脚本、第三方字体或跟踪工具。访问网站时，GitHub 可能按其隐私政策处理必要的访问日志。详情参见 GitHub 隐私声明。App 不会在后台自动访问此网站。

7. 未成年人

App 不提供社交、聊天或公开内容发布功能，不主动要求未成年人提交个人信息。未成年人应在监护人指导下选择照片权限，并避免通过公开支持渠道分享个人信息。

8. 政策更新与联系方式

功能或数据处理方式发生变化时，我们会更新本政策的内容与日期。涉及权限或数据处理的实质变化将按适用要求说明。
